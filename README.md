# Giovani Aditya Krisna Sunu — Portfolio

Static single-page portfolio site.

## Deploy with GitHub Pages

The included GitHub Actions workflow deploys the site whenever changes are pushed to `main`. After adding the repository to GitHub, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. The workflow will publish the site and report its URL in the Actions run.

The page uses Tailwind CSS, Boxicons, and Google Fonts from their CDNs, so a browser needs an internet connection to load those assets.
